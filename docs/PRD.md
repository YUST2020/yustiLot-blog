# 产品需求文档 (PRD)

## 1. 项目愿景
构建一个包含前台展示与后台管理的个人全栈网站。
- **前台**: 清新、现代化的个人展示与博客阅读体验。
- **后台**: 安全、便捷的内容管理系统 (CMS)。

## 2. 功能模块详解

### 2.1 核心前台模块 (Public)
与之前规划一致，包含：
- **首页**: Hero 全屏图、个人概况、最新文章。
- **博客**: 文章列表、文章详情 (Markdown 渲染)。
- **导航**: 透明变色导航栏。

### 2.2 后台管理模块 (Admin)
独立于前台的 `/admin` 路由区域，需登录访问。

#### A. 登录页
- **功能**: 管理员身份验证。
- **输入**: 用户名/邮箱、密码。
- **安全**: 防止暴力破解，登录状态持久化。

#### B. 仪表盘 (Dashboard)
- **概览**: 文章总数、最近更新时间等简要统计。

#### C. 文章管理 (Blog Management)
- **列表**: 展示所有文章，支持状态筛选 (草稿/已发布)、搜索。
- **编辑器**: 
  - 全屏 Markdown 编辑体验。
  - 支持实时预览。
  - 设置文章属性: 标题、Slug (URL别名)、封面图、摘要、标签、发布时间、是否公开。
- **操作**: 新增、编辑、删除 (软删除或物理删除)。

#### D. 个人信息设置 (可选)
- 修改头像、昵称、首页 Slogan 等配置（可后续迭代）。

### 2.3 用户模块 (User System)
- **角色**: 目前仅需支持 **管理员 (Admin)**。
- **功能**: 
  - 用户登录/登出。
  - 密码修改。
  - (未来) 支持多用户或访客评论。

## 3. UI/UX 风格
- **前台**: 保持清新、扁平、毛玻璃风格 (Argon-like)。
- **后台**: 
  - 侧边栏布局 (Sidebar Layout)。
  - 简洁高效，注重内容编辑体验。
  - 使用 Shadcn `Table`, `Form`, `Dialog` 等组件构建。

## 4. 技术实现要点
- **鉴权**: 使用服务端 Session 或 JWT 保护 `/api/admin/*` 接口及 `/admin/*` 页面。
- **Markdown**: 
  - 后台: 使用 Vue 组件库中的 Markdown 编辑器。
  - 前台: 后端返回 Markdown 文本，前端解析为 HTML 并应用 Typography 样式。
